One-time setup

You need to connect this app to a free Supabase database. Follow the steps below — it takes about 5 minutes and you only do it once.

1 Create a free Supabase account

Go to supabase.com, sign up free, and create a new project. Call it anything (e.g. "lcbiology").

2 Create the database tables

In your Supabase project, go to SQL Editor and run this query:

create table questions ( id bigint generated always as identity primary key, topic text, year text, marks text, question text, marking_scheme text, file_name text, created_at timestamptz default now() ); create table resources ( id bigint generated always as identity primary key, title text, topic text, type text, url text, content text, created_at timestamptz default now() ); alter table questions enable row level security; alter table resources enable row level security; create policy "public read" on questions for select using (true); create policy "public read" on resources for select using (true); create policy "public write" on questions for all using (true); create policy "public write" on resources for all using (true);

3 Paste your Supabase keys below

In Supabase go to Project Settings → API. Copy your Project URL and anon/public key.

Please enter both values.
